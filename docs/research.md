# AIHOT 研究与产品取舍

参考：https://github.com/KKKKhazix/AIHOT
研究版本：ce8348477438cce2b417c1403290a511c812a7c5，2026-10-26。

## 可借鉴

- 配置化来源与采集实现分离，RSS、网页列表、JSON 等进入统一流程。源码：`packages/backend/src/sources/collect.ts`、`sources/filters.ts`。
- URL 规范化后先去重，再抓详情。源码：`sources/collect.ts:66–88`、`lib/url.ts:5–35`。本站保留业务查询参数，只移除明确的营销参数。
- 失败不推进成功状态，记录来源健康。源码：`sources/collect.ts:256–277`。本站保留抓取错误、成功时间和待复核信息。
- 来源分层、统一出口。本站社区内容只能作为线索，官网条款才能支持正式发布。

## 不照搬

AIHOT 是配置化订阅采集，不是全网搜索引擎。它的 `industry/prompts/selection-score.md` 对活动、限免评分很低；其新闻热度与时效标准不适合福利。本项目没有复用评分、提示词、源码或视觉布局。

福利的评价重点是：入口是否可核对、净权益、资格与付费门槛、地区、期限、证据。人气与发布时间不能代替领取可能性。

首版不用多进程后端、向量聚类和多模型写作，而用零依赖静态站 + 可独立执行的数据流水线。候选不自动发布，避免模型从未明确的规则中补造数字。

## 初始资料边界

12 条发布内容在 2026-10-26 阅读官方公开说明核验，未登录逐个实领。每条 `source.url` 是对应官方依据，`source.evidence` 是核验摘要。所有首次收录时间使用本次真实收录时间，不回填为活动上线日。

两条研究结果暂留本机待审区：Qoder 1024 国际活动规则存在但活动入口本次返回 404；火山方舟免费 Token 页面直接读取不到正文。没有把它们当作可领取内容公开。

常见免费层、教育方案不伪装限时促销，统一标“长期权益 / 官方未公布截止时间”。初始全球内容不表示中国或全球所有地区一定可用。
